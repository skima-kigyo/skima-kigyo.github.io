# リマインド文面ひな形

自分宛て・チームの仲間宛て・先生や窓口への連絡で使える文面です。【　】の中を自分の内容に書き換えて使います。
送る相手と内容は自分で確認してから送ってください。授業の課題の代行を頼む・頼まれる文面は扱いません。

## 1. 自分宛て（カレンダー・メモに入れる）
```
【課題名】の提出は【月/日 時刻】まで。
残りの作業：【やること1】／【やること2】
今日やるのは【やること1】の15分だけ。
```
使う時の目安：期限の3日前・前日・当日の朝に1回ずつ（カレンダーの通知に設定）。

## 2. グループ課題の仲間宛て
```
お疲れさまです。【課題名】について、【月/日】までに【担当部分】の共有をお願いできますか。
こちらは【自分の担当】を【月/日】までに出します。
難しそうなら、いつ頃なら出せそうか教えてください。
```

## 3. 期限や形式を先生・窓口に確認する
```
【科目名】の【担当の先生の名前】先生
お世話になっております。【学部・学年】の【氏名】です。
【課題名】について、【確認したいこと（例：提出形式、期限）】を教えていただけますでしょうか。
シラバスと授業の案内を確認しましたが、【分からなかった点】が分かりませんでした。
お手数をおかけしますが、よろしくお願いいたします。
```

## 4. 期限に遅れそうな時の連絡（早めに）
```
【科目名】の【担当の先生の名前】先生
【学部・学年】の【氏名】です。
【課題名】の提出について、【事情を事実だけ】のため、【月/日】の期限に間に合わない見込みです。
【月/日 時刻】までには提出できます。対応についてご指示をいただけますでしょうか。
```
※ 対応を決めるのは先生です。受け入れられるかは授業のルール次第なので、約束せずにお願いの形にします。

## 5. サークルなど身近な人に送る出欠・期限のお知らせ（自動化を人に提供する時の型の一つ）
```
【行事名】の出欠を、【月/日】までに【方法】で教えてください。
日時：【月/日 時刻】　場所：【場所】
締め切りを過ぎた場合は【扱い】とします。
```
※ 名簿・連絡先など個人情報を預かる場合は、扱い方を決めて、本人に伝えてから使います。

## 5分でできる最初の一歩
1 の文面を、今いちばん期限が近い課題用にコピーして、カレンダーの予定のメモ欄に貼る。
