# 参考文献の整形ひな形

役割：集めた資料の情報を **書式をそろえて並べる** だけです。何を引用するか・何と書くかは、あなたが元の資料を読んで決めます。文章の代筆はしません。
書式は授業や先生の指定が最優先です。指定があればその書式に合わせて直してください（同じフォルダの Excel 版「参考文献の整形ひな形.xlsx」は、式を直せば変えられます）。

## 1. 先に集める情報（資料 1 件ごとに）
| 種類 | 控えておく情報 |
|---|---|
| 書籍 | 著者・発行年・書名・出版社 |
| 論文 | 著者・発行年・論文タイトル・掲載誌名・巻号・ページ |
| Web | 運営者または著者・公開年・ページタイトル・サイト名・URL・閲覧日 |

控えるのは、資料を見つけたその場がいちばん楽です（あとで探し直すと時間がかかります）。

## 2. 並びの一例（指定が無い時の仮の形）
```
書籍：著者（発行年）『書名』出版社．
論文：著者（発行年）「論文タイトル」『掲載誌名』巻号・ページ．
Web ：運営者（公開年）「ページタイトル」サイト名．URL（閲覧日：YYYY年M月D日）
```

## 3. 入力の例（架空の書き込み例です。実在の資料ではありません）
```
書籍：著者名（2020）『書名』出版社名．
Web ：運営者名（2025）「ページタイトル」サイト名．https://example.com/（閲覧日：2026年11月15日）
```

## 4. 整えたあとの確認
- □ 授業で書式の指定があった → それに合わせた
- □ 本文で引用した資料が、すべて一覧に載っている
- □ 一覧にある資料を、実際に自分で開いて読んだ
- □ 並び順（五十音・アルファベット・引用順）が指定どおり

## 5分でできる最初の一歩
今書いている課題で使った資料を 1 件だけ、Excel 版に入力して、J 列に出る形を見る。
